## QUICK REVISION

### Power Query
- Load data from Excel CSV SQL databases
- Remove rows columns split replace values
- Fill nulls change types unpivot transpose
- Append = rows like UNION ALL
- Merge = columns like JOIN
- Close and Apply to save

### DAX Functions
- Aggregate = SUM AVG MIN MAX COUNT DISTINCTCOUNT
- Iterator = SUMX AVERAGEX MINX MAXX
- Filter = CALCULATE ALL ALLSELECTED ALLEXCEPT
- Logical = IF AND OR SWITCH NOT
- Text = CONCATENATE LEFT RIGHT MID UPPER LOWER
- Date = TODAY NOW YEAR MONTH DAY DATEDIFF
- Advanced = RANKX VALUES VAR RETURN DIVIDE

### Key Patterns
- Percentage = DIVIDE(SUM, CALCULATE(SUM, ALL))
- Cumulative = VAR rank RETURN CALCULATE FILTER
- Cumulative % = DIVIDE(Cumulative, Total ALL)
- Rank = RANKX(ALL(col), measure, , DESC)

### Evaluation Context
- Row Context = row by row Calculated Columns
- Filter Context = filtered data Slicers CALCULATE
- Context Transition = CALCULATE converts row to filter

### Charts
- Bar Column Stacked Line Area Pie Donut
- Tree Map Scatter Map Gauge KPI Card
- Table Matrix Slicer Funnel Bookmark

### Data Model
- Star Schema = Fact + Dimension simple fast
- Snowflake = normalized more complex
- One to Many = most common relationship
- Solid line = Active Dotted = Inactive

### Dashboard Rules
- Title = largest text always
- Thousand Separator = ON
- Display Units = NONE
- Max 2 to 4 colors only

### Advanced Features
- Bookmarks = switch views with buttons
- Pareto = 80/20 cumulative analysis
- RANKX with ALL = global dynamic ranking
- VAR RETURN = store complex expressions
