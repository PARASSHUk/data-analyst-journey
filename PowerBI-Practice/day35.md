## QUICK REVISION

### Power Query
- Load Excel CSV SQL databases
- Remove rows split replace fill nulls
- Change types unpivot transpose
- Append = rows Merge = columns
- Close and Apply to save

### DAX Functions
- Aggregate = SUM AVG MIN MAX COUNT
- Iterator = SUMX AVERAGEX MINX MAXX
- Filter = CALCULATE ALL ALLSELECTED
- Logical = IF AND OR SWITCH NOT
- Text = LEFT RIGHT MID UPPER LOWER
- Date = TODAY YEAR MONTH DAY DATEDIFF
- Advanced = RANKX VALUES VAR RETURN

### Key Patterns
- Percentage = DIVIDE(SUM, CALCULATE(SUM, ALL))
- Cumulative = VAR rank RETURN CALCULATE FILTER
- Rank = RANKX(ALL(col), measure, , DESC)

### Evaluation Context
- Row Context = Calculated Columns SUMX
- Filter Context = Slicers Visuals CALCULATE
- Context Transition = CALCULATE converts row

### Charts
- Bar Column Stacked Line Area
- Pie Donut Tree Map Scatter Map
- Gauge KPI Card Table Matrix Slicer

### Data Model
- Star Schema = Fact + Dimension fast simple
- Snowflake = normalized complex
- One to Many = most common
- Solid = Active Dotted = Inactive

### Dashboard Rules
- Title = largest text always
- Thousand Separator = ON always
- Display Units = NONE always
- Max 2 to 4 colors only

### Advanced Features
- Bookmarks = switch views with buttons
- Pareto = 80/20 cumulative analysis
- VAR RETURN = store complex expressions
- Conditional Formatting = numeric only
